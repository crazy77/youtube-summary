# Permissions Summary for Chrome Web Store Review

## Storage Permission
**Purpose:** Save user preferences and enable cross-page functionality
- Store user settings (button enable/disable, custom prompts, language preference)
- Temporarily transfer data from YouTube to Gemini for auto-input feature
- Sync settings across devices

## Host Permissions

### youtube.com domains
**Purpose:** Add AI search buttons to YouTube videos
- Insert search buttons on video pages
- Extract video URLs for AI analysis
- Detect dynamic content loading in YouTube's SPA

### gemini.google.com domain  
**Purpose:** Provide seamless auto-input functionality
- Automatically input prompts on Gemini pages
- Submit analysis requests with one click
- Eliminate manual copy-paste operations

## Privacy Commitment
- No personal data collection
- No browsing history access
- Only user-configured settings stored
- Minimal permissions for intended functionality
- Transparent data usage

# 스토리지/호스트 권한 사용 근거 (한국어 요약)

## 스토리지 권한
**목적:** 사용자 설정 저장 및 페이지 간 기능 연동
- 사용자 설정 저장 (버튼 활성화, 프롬프트, 언어 설정)
- YouTube→Gemini 자동 입력을 위한 임시 데이터 전달
- 기기 간 설정 동기화

## 호스트 권한

### YouTube 도메인
**목적:** YouTube 영상에 AI 검색 버튼 추가
- 영상 페이지에 검색 버튼 삽입
- AI 분석용 영상 URL 추출
- YouTube SPA 동적 콘텐츠 감지

### Gemini 도메인
**목적:** 원클릭 자동 입력 기능 제공
- Gemini 페이지에서 자동 프롬프트 입력
- 원클릭 분석 요청 제출
- 수동 복사-붙여넣기 작업 제거

## 개인정보 보호
- 개인정보 수집 없음
- 브라우징 히스토리 접근 없음
- 사용자 설정값만 저장
- 최소 권한 원칙 준수
- 투명한 데이터 사용
